# Build a website with AI — this week

**Scan to start:** [QR → https://student-sites.org/start]

**Class passcode:** ____________

1. In your pair, pick a site name: lowercase letters, numbers and hyphens (e.g. `sams-recipes`).
2. Scan the QR code and download the starter kit.
3. Use Claude Code or ChatGPT to build your site — the starter kit tells the AI the rules.
4. Open `index.html` in your browser to check it. Iterate!
5. Zip your folder and submit it on the site with the passcode.
6. Keep your review link. Your teacher approves each version before it goes live at
   `student-sites.org/students/<your-site-name>/`.

Rules: keep it classroom-appropriate, first names only, no contact details, only images you're allowed to use.
