# StudySupply

A classroom-friendly static e-commerce prototype for students shopping for school supplies.

## Features
- Responsive catalogue with 12 school supplies
- Search, category filters and price/name sorting
- Working add-to-bag shopping cart
- Quantity controls and cart total
- Demo checkout message
- Responsive layout for desktop and mobile
- No build tools or server required

Open `index.html` directly in a browser to view the site.
