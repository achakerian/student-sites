# Eurobound — 10 Days Across Europe

A one-page static class showcase website for a student trip through Paris, Amsterdam and Berlin.

## Open the site

1. Keep all files together in this folder.
2. Double-click `index.html`.
3. The site opens directly in a web browser with no server or install step.

## Files used by the site

- `index.html` — all page content and the three main sections.
- `styles.css` — layout, typography, colour, responsive styling and vector-map presentation.
- `script.js` — controls the single interactive departure-checklist button.
- `meta.json` — showcase metadata required by the class template.

## Design notes

The site uses no external fonts, libraries, scripts or image assets. All visual decoration is original HTML/CSS/SVG, so the site remains small and works offline.

## Trip-data note

Opening hours, ticket rules, prices and rail schedules can change. The itinerary is a researched planning example checked in August 2026; students should reconfirm details for their exact travel dates before booking.
