How reviewing works

  1. Look at the preview

    Each card embeds the submitted site straight from its branch (nothing is live yet). Use Full preview to open it in its own tab. Check the ⚠️ list if present — those are scripts, iframes or stylesheets loaded from other domains.

  2. Publish: merge the PR

    Click Open PR → Merge pull request → Confirm merge. The site is live at student-sites.org/students/<name>/ within about a minute, and the index updates itself.

  3. Reject: close the PR with a comment

    On the PR, write a one-line comment saying what to change, then Close pull request and click Delete branch. Students read your comment via their review link and resubmit (which opens a fresh PR).

  4. Resubmissions

    If a pair resubmits while their PR is still open, the same PR is updated in place and the submission number goes up. If they resubmit after a merge, a new PR appears — merge it to replace the published version.

From the terminal

gh pr list --search "Site:" --state open
gh pr merge 12 --merge --delete-branch
gh pr close 12 --delete-branch --comment "Please remove the surnames on the About page and resubmit."

After the activity

Revoke the student-sites-worker token at github.com/settings/personal-access-tokens. That disables uploads; everything already merged stays published.
